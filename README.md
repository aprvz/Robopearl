# Robo Pearl

Australian restaurant robotics website — static site for GitHub Pages (`robopearl.com`).

## Pages
- `index.html` — Home
- `robots.html` — Robot catalogue (6 Pudu models)
- `compare.html` — Which robot is right for you?
- `contact.html` — Enquiry form → `enquiry@robopearl.com`

## Robots (botHUB-sourced)
PuduBot 2 · SwiftBot · BellaBot · PuduBot · HolaBot · KettyBot

## Deploy
Pushes to `main` deploy via GitHub Pages Actions.
